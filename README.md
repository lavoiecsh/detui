# DeTUI
Development Terminal User Interface

## Features
### Left Panel
#### Statistics
Version Control (number of staged/unstaged/commits ahead/commits behind)
Token Usage (Cost, Model)
#### File Explorer
Open files using $EDITOR
Preview files using $PAGER
Version Control Indicators (staged, unstaged)
